# Challengue-Alura-Store
En este proyecto se empleó Python como herramienta principal para llevar a cabo un análisis exploratorio de datos con el propósito de asistir al señor Juan en cinco áreas estratégicas del negocio:

  * Análisis de facturación
  * Distribución de ventas por categoría de producto
  * Evaluación de la calificación promedio por tienda
  * Identificación de productos con mayor y menor rotación
  * Cálculo del costo promedio de envío por tienda



El análisis se realizó a partir de datos correspondientes a cuatro tiendas, y los principales hallazgos son los siguientes:
	 
  *  Tienda 1 presenta la facturación más alta, aunque también registra el mayor costo promedio de envío.
  *  Tienda 2 alcanza la calificación promedio más elevada, lo cual sugiere una alta satisfacción del cliente.
  *  Tienda 3 refleja la facturación más baja, pero compensa con menores costos logísticos.
  *  Tienda 4 destaca por tener un alto volumen de productos entre los más vendidos, evidenciando un buen desempeño comercial.

Este análisis proporciona una base objetiva para la toma de decisiones, permitiendo al señor Juan identificar oportunidades de optimización en distintas dimensiones operativas y comerciales de sus tiendas.
